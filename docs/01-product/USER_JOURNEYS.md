# Key User Journeys
1. Lead → customer/KYC → unit → quotation/discount → reservation → contract → installments → receipt/bank → AR settlement → handover → dashboard.
2. Site material request → PR → approval → RFQ → supplier → PO → delivery/GRN → warehouse → issue → project cost → invoice → 3-way match → payment → GL.
3. Contractor work → measurement → engineer approval → IPC → retention/advance recovery → payable → payment → project cost → GL.
4. Employee → attendance/OT/leave → payroll → HR/Finance approval → payslip → bank → project/cost-center allocation → GL.
5. Executive KPI → project → department/cost center → source transaction → evidence → creator/approver → payment → journal → ledger.
