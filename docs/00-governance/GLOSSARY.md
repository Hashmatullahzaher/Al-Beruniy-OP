# Glossary
Type A Account = system user/login. Type B Account = business party (customer/supplier/contractor/employee). Type C Account = financial ledger account. RBAC = role-based access control. SoD = segregation of duties. WBS = work breakdown structure. BOQ = bill of quantities. PR/RFQ/PO/GRN = purchase requisition/request for quotation/purchase order/goods receipt note. IPC = interim payment certificate. EAC/CTC/BAC = estimate at completion/cost to complete/budget at completion. AR/AP/GL = accounts receivable/payable/general ledger.
AI Core = cross-cutting enterprise intelligence control plane spanning ABOS.
Model Gateway = provider-neutral service that connects ABOS to one or more LLM/model providers using approved credentials.
Enterprise Knowledge Plane = governed indexed representation of ABOS documents, entities, events, metrics and relationships for AI retrieval/reasoning.
RAG = retrieval-augmented generation grounded in authorized source records/documents.
Typed Tool = explicit schema-defined AI-callable domain operation routed through authorization and business services.
Machine Identity = non-human service identity with explicit scoped permissions for background system processes.
Telegram Gateway = secured adapter between Telegram Bot API and ABOS identity/AI/notification services.
