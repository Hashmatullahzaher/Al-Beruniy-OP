# Shared Acceptance Contract
A0 Documentation/Blueprint: domains/roles/workflows documented, blueprints present, unknowns explicit. A1 Identity/RBAC: user-party separation; role/project/department/field scopes server-enforced; negative tests fail closed. A2 Master/Multi-project: governed unique masters; project isolation and authorized consolidation. A3 Sales/Collections: unit/contract/installment/receipt/overdue workflows reconcile with AR. A4 Finance: balanced journals, immutable posting/reversal, subledgers reconcile, dimensions propagate. A5 Construction/Cost: WBS/BOQ/budget/commitment/actual/forecast and source-cost traceability work. A6 Procurement/Inventory/Supplier/Contractor: PR→PO→GRN→invoice→match→pay, stock and IPC flows complete with SoD. A7 HR/Payroll: deterministic payroll, approvals, allocations, confidentiality. A8 Documents/Workflow: evidence/version/approval/audit preserved. A9 BI/AI Core/Telegram/Portals/Integrations: reports reconcile and drill down; AI Core is system-wide with provider-neutral LLM gateway, governed enterprise knowledge plane, typed tools and audited model/tool/source usage; Telegram identities bind to ABOS users and reuse the same permission/workflow/audit path; portals remain own-party only; integrations are secure/idempotent/audited. A10 Operations: migration, backup/restore, secrets, monitoring, security review, browser UAT and rollback meet approved requirements. Security, financial-integrity, data-loss, privacy or unrecoverable correctness failures are blockers.
