Three kinds of number — never mixed

ACTUALposted by Finance / domain services · reconciles to GL · authoritative
FORECASTdeterministic rules (EAC · cash-flow schedule) · versioned · explainable
AI RECOMMENDATIONmodel inference with confidence · labelled · never totalled with actuals · never posted
Dashboards, exports and AI answers carry the label. An executive can always tell what the books say from what a model thinks.

Semantic layer → Knowledge Plane → AI Core

Governed measures as AI inputsRevenue · collected · overdue · EAC · SPI/CPI · payables — each with definition, owner, grain and security rule. AI uses the same definition a dashboard uses; no private recomputation.
AI feature storederived features for collection risk, delay and overrun models — built from DWH, versioned, security-tagged by project and party.
AI executive summaries“What changed?” narratives generated from measure deltas with links back to reports and transactions.
Never: AI querying the warehouse with free SQL · unlabelled forecasts · a measure the semantic layer does not define.
