Two identities, one rule

Machine Identity MID-01
scoped service identity for indexing & background monitoring. Enterprise-wide awareness; never anonymous superuser; can raise alerts/tasks, cannot decide.
Human user (Type A)
receives only what that user is authorized to see — project, department, field, party — regardless of what the Core knows.
“Knows everything” = the Core indexes permitted enterprise knowledge. It does not mean any user gets the whole database. BP-02 BP-23
