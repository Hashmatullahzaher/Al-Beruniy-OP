Segregation of Duties (SoD)

Creates
Requester (Site Eng / Storekeeper) → PR
Sources
Procurement Officer → RFQ, quotes, comparison
Reviews
Engineer (technical) + Procurement (commercial)
Approves
Proc Mgr / Finance / CFO by amount tier
Receives
Storekeeper → GRN + QC inspection
Registers Invoice
AP Accountant
Approves Payment
FM ≤ T1 · CFO ≤ T2 · CEO > T2
Pays
Treasury / Bank — never the creator
Rule: requester ≠ approver ≠ receiver ≠ payer. System blocks same-user across conflicting steps.
