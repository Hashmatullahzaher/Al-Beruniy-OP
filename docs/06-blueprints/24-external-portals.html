External Users, Cleanly Separated from Employees
Self-service surfaces that see only their own party data — never internal operations.
Version1.0 Date2026-09-17 ConnectorPORT-01 Sheet24 / 26
LEGEND Customer portal Supplier portal Contractor portal → maps to internal SEC-01 own-party data only
SEPARATION PRINCIPLE — external identity ≠ employee identity
External users are Type A logins bound to one Type B party (their own customer/supplier/contractor record). Row-level security guarantees a portal user sees only their own contracts, invoices and documents — never other parties, never internal finance, HR or other projects. All portal submissions enter the same Workflow Engine WF-01 and post through the same Finance engine FIN-GL-01 as internal actions.
