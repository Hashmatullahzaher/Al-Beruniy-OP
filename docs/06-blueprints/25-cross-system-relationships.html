Relationships by Flow Type

Financial Flow → Sales→AR · Procurement→AP · Contractor→Payable · Payroll→Employee Payable · WH Issue→Project Cost · Expense→GL. Every module posts Dr/Cr to the Financial Engine.
Data Flow → All modules stamp Project · Cost Center; events (GRN, receipt, IPC) stream to DWH/BI & AI. Projects & Master Data feed every module.
Document Flow → Contracts, drawings, POs, IPCs, invoices & receipts all resolve to Document Mgmt; each transaction links to its evidence.
Approval Flow → Every side-effect (PO, payment, discount, IPC, payroll, budget) passes the Workflow ring (WF-01) before it posts.
User Flow → Employees act inside RBAC; Customers/Suppliers/Contractors act via portals, scoped to their own party (BP-24).
AI / Channel Flow → Web/Telegram → Identity → Permission → AI Core → Knowledge/Typed Tool → Domain Service → Workflow/Finance/Audit. LLM providers connect only through the Model Gateway. QUALITY-CONTROL CHECK — no orphan modules
