The five governed flows

Business API Web/Mobile/Portal → API Gateway → Identity → Domain service → OLTP. Synchronous; authorization server-side.
Domain event Domain service → Event bus → Finance / Notifications / AI Knowledge Plane (tagged projection) / DWH. Idempotent, replayable.
AI model traffic AI Core → Model Gateway → selected provider. Minimum context · classification-checked · audited · cost-metered. Returns to Core, never to a module.
Telegram traffic Inbound: Bot API → Telegram Gateway → binding → AI Core / Document Service. Outbound: Event / Workflow / AI alert → Notification Service → Telegram Gateway → authorized private chat / allow-listed channel.
Analytics OLTP → CDC/ELT → DWH → Semantic layer → BI & Knowledge Plane features. Read-only; reconciles to GL.
