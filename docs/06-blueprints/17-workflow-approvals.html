Worked Examples — same engine, different policies

Purchase Request
Requester → PM → Proc Mgr (budget check)
Purchase Order
Proc Mgr → FM ≤T1 → CFO ≤T2 → CEO >T2
Expense
Employee → Dept Mgr → Finance → CFO (by amount)
Customer Discount
Agent → Sales Mgr → Sales Dir → CFO (by %)
Sales Contract
Sales Mgr → Legal → Finance → Sales Director
Contractor Payment (IPC)
QS → Site Eng → PM → Finance → CFO
Supplier Payment
AP → FM ≤T1 → CFO ≤T2 → CEO >T2
Payroll
HR Officer → HR Mgr → Finance → CFO
Budget / Revision
PM → Project Dir → CFO → CEO
Change / Variation Order
Site Eng → PM → Project Dir → CFO (cost impact)
Segregation of Duties is enforced across all: the person who creates cannot be the person who approves or pays.

Decision Node Logic

Amount ≤ approver limit?
Yes → approve & execute.
No → escalate to next tier.
Missing info → return to requester.
Timeout → auto-escalate + notify.
