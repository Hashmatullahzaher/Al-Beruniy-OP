# Build Master Prompt
Read repository documentation before coding. Treat Acceptance Contract, domain rules and approved blueprints as binding. Implement working software, not plans. For each milestone: map criteria → implement → test → self-audit → fix → commit → continue. Never invent missing official rates, thresholds, legal wording or accounting policies. Preserve RBAC, project isolation, SoD, accounting integrity, audit trails and traceability. AI uses typed tools/domain services, not arbitrary SQL. Report branch, exact SHA, tests/evidence, non-blocking items and blockers.
